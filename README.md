# GIT ROOSEE Mobile

Responsive mobile-first UI prototype for ROOSEE Intelligent Network.

## Preview
Open `index.html` in a browser or enable GitHub Pages (Settings → Pages → Deploy from a branch → main / root).

## Features
- Samsung Galaxy S23 Ultra responsive dashboard
- Navigation to device, user, statistics, settings, security, service sections
- Zalo Mini App HTTPS URL launcher (user-provided)
- No fabricated real network metrics; placeholders until official API integration

## Limitations
This is a UI prototype, not an official ROOSEE product or an Android APK. Zalo Mini Apps may only function within the Zalo application. Do not put passwords, tokens or other secrets into public GitHub repositories.

## Next steps
